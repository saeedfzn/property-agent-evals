Property agent evals

A property-management triage agent in TypeScript, Node.js and PostgreSQL, with sub-agents, tool calling and zod-validated structured outputs. A Python eval harness grades it. This page reads the committed eval reports for two prompt versions.

  • TypeScript
  • Node.js
  • PostgreSQL (PGlite)
  • Python
  • zod
  • Anthropic SDK
  • GitHub Actions

What is simulated: the model. These numbers come from a scripted, deterministic fixture provider, so latency is simulated and cost is estimated from token counts at list price. The v1 to v2 improvement is scripted too: the fixture invents an appointment when its prompt tells it to promise one. What is real: the orchestration, tool calls against PostgreSQL, validation and retries, tracing, the graders and the CI gate all execute on every run. The numbers show that the graders catch invented facts and that the gate blocks the build; they are not a benchmark of a live model. All data is fictional.

Why v1 fails

The v1 drafting prompt says to "always tell the resident when they can expect a visit". For messages where nothing is booked, the reply invents a date or time. The grader parses each date, time, flat number, job reference and £ amount from the reply text and checks it against the database, scoped by the golden case:

  • to the true flat, so a real booking for another flat does not count;
  • to the one job the message is about, so a different job booked on the same flat that day does not make an invented visit true;
  • to the kind of question, so a rent due date cannot stand in for a visit date.

Rules the model cannot override

  • Emergencies. Deterministic rules run on the raw message. The model can raise urgency but never lower it, and the safety wording is a fixed template.
  • Account data. The lease, rent and job tools refuse any flat the sender is not the resident or landlord of, so another household's data reaches neither the model nor the reply, whatever flat the message names.
  • Writes. The agent only proposes a work order. A named human approves it, and a full run of the golden set writes no rows.
  • Outages. If a model call fails after its retries, the message goes to a human with a holding reply. A gas message still gets its emergency verdict and safety wording.
